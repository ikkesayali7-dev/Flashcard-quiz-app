# Flashcard Quiz App - CodeAlpha Internship

## Task
Flashcard Quiz App

## Features
- Question and answer flashcards
- Show/Hide Answer
- Next and Previous navigation
- Add flashcard
- Edit flashcard
- Delete flashcard
- Progress indicator
- Responsive design

## Technologies
- HTML
- CSS
- JavaScript

## How to run
Open `index.html` in Google Chrome or another web browser.

## Internship submission
1. Test the project.
2. Upload the project folder to a GitHub repository named according to the internship instructions.
3. Record a short video explaining the project and its features.
4. Add the GitHub link with the video on LinkedIn.
5. Submit the project using the internship Submission Form.
