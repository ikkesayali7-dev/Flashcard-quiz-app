# Random Quote Generator

## CodeAlpha App Development Internship - Task 2

A simple Random Quote Generator built using HTML, CSS and JavaScript.

### Features
- Shows a random quote on page load.
- New Quote button generates another quote.
- Displays the quote author.
- Clean responsive design.
- Avoids immediately repeating the same quote.

### Technologies
HTML, CSS, JavaScript

### How to Run
Open `index.html` in a web browser and click **New Quote**.
